how to make the .py into .exe:
-> open cmd
-> pip install pyinstaller
-> cd C:\Users\evafa\OneDrive\Desktop\Research (wherever the .py file is)
-> make sure breezypythongui is in the same location as .py file
-> python -m PyInstaller --clean --onedir --collect-all scipy --collect-all numpy --collect-all PIL image_processor_gui.py
